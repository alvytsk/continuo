# Milestone 3 acceptance coverage

`docs/superpowers/specs/2026-09-09-continuo-finite-http-design.md` §12 lists eighteen acceptance items, H1 through H18, that M3's implementation must demonstrate. This page is the coverage map: for each item, which test(s) discharge it, and — where discharge is partial or absent — exactly why.

Two rows are not fully discharged, and are carried as known debt (`docs/m1-known-debt.md`, "Milestone 3 — carried debt") rather than closed silently:

- **H6** is discharged as a composite rather than by one test, because `RedirectRejection::Downgrade` is a distinct variant from `UnsupportedScheme` and a genuine HTTPS→HTTP downgrade cannot be staged against this project's TLS-less loopback test server.
- **H17**'s first half — proving that a byte-seekable source with an unseekable demuxer is never advertised `Native` — is undischarged. No fixture reproduces the scenario against any demuxer this project enables; see the known-debt entry for the precise mechanism.

**H16 was a false green until M3.1's Task 7 fix round corrected it** (see its row's Notes below): `tests/http_resume.rs::the_protection_survives_a_process_boundary` passed even with checkpoint protection fully neutered in `src/session.rs`, because its rig consumed the `Loaded` event before the `Session` meant to observe it existed, so no write was ever attempted for the test to gate. Recorded here rather than silently fixed, since a coverage map that once claimed a defect-free row it could not actually prove is exactly the failure mode this page exists to catch.

## Milestone 3.1 — estimated seeking and position provenance

`docs/superpowers/specs/2026-09-10-continuo-estimated-seek-design.md` §6 lists
the acceptance items for the estimated-seek amendment. Most of them were
already discharged by Tasks 4, 5, 6 and 9 before this row was ever written;
this task's own contribution is the four cross-process rows at the bottom
(cross-process estimated resume, upgrade at session level, the estimate-only
entry, and the refused-resume-through-persistence row), each new in
`tests/estimated_resume.rs` or `tests/resume_contract.rs`, plus an honest
audit of everything else. Unlike M3's H6 and H17, **every row below is fully
discharged** — the audit found no genuine gap to carry as debt. One row (the
fifth, below the main table) is discharged but asymmetrically falsifiable —
mutation-tested and documented as such in its own Notes, in the same spirit
as H6's composite discharge above, rather than left to look like something
it is not.
