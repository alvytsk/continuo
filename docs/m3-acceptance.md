# Milestone 3 acceptance coverage

`docs/superpowers/specs/2026-09-09-continuo-finite-http-design.md` §12 lists eighteen acceptance items, H1 through H18, that M3's implementation must demonstrate. This page is the coverage map: for each item, which test(s) discharge it, and — where discharge is partial or absent — exactly why.

Two rows are not fully discharged, and are carried as known debt (`docs/m1-known-debt.md`, "Milestone 3 — carried debt") rather than closed silently:

- **H6** is discharged as a composite rather than by one test, because `RedirectRejection::Downgrade` is a distinct variant from `UnsupportedScheme` and a genuine HTTPS→HTTP downgrade cannot be staged against this project's TLS-less loopback test server.
- **H17**'s first half — proving that a byte-seekable source with an unseekable demuxer is never advertised `Native` — is undischarged. No fixture reproduces the scenario against any demuxer this project enables; see the known-debt entry for the precise mechanism.
